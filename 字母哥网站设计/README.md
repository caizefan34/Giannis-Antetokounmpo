# 字母哥介绍网站（静态单页）

这是一个可直接离线打开的单页网站，用来介绍 **字母哥 Giannis Antetokounmpo**：包含成长故事、生涯时间线（可筛选）、球风拆解、荣誉墙、经典时刻、FAQ，以及明暗模式等交互。

## 如何打开

- 直接双击打开 `index.html`
- 或用浏览器打开 `index.html`

## 文件结构

- `index.html`：页面结构与内容
- `styles.css`：样式（现代 UI、响应式、暗色/亮色主题）
- `script.js`：交互（导航高亮、时间线筛选、折叠面板、复制、回到顶部、主题切换）
